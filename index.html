        Host online

        Open a lobby with a six-letter code. Friends anywhere in the world join with it. Nothing to install, no server to run.

        Connection settings

        Games are introduced through the free public PeerJS server. If it is ever down, anyone can run their own (npx peerjs --port 9000) and every player enters its address here.

        Relay server (optional). Only needed when a friend’s network blocks direct connections. Paste TURN details from any provider, such as a free Metered or Cloudflare account. Either the host or the joining player can set it.
